# T2 按卡执行

## 目标

只跑已锁定内容：读 T0 + T1-04 + cases / 页面卡，产出本轮结果与证据。不发现新接口，不发明 path/body。

## 输入

- `artifacts/_project/T0-01-测试手册.md`（接口类必齐）  
- `T1`：范围与验收、接口卡、页面卡、`verify/`  
- 本轮计划（r1/r2 或失败重跑）

## 步骤

### 0. 前置检查

- 本轮 verify 条：卡均为「已取样」；cases 无卡外 path/键。否则停 → 回 T1。  
- 接口类：T0 探活先跑；探活失败 → 本轮接口条标无法证明/未执行，修环境或手册后再跑。

### 1. 执行

1. 读 `env.example`，本地填 `env.local`（不入库）。  
2. 跑 `verify/run.ps1|sh` → `out.txt`。  
3. 手工/查库：按页面卡或 AC 步骤做，记操作与观察。  
4. r1 顺序见生命周期 › 执行循环。

### 2. 判定

| 结果 | 何时 |
|------|------|
| 通过 | 观察与卡/AC 一致，有证据 |
| 失败 | 可复现不符 → 转 T3 出 BUG |
| 无法证明 | 环境不可达、缺权限、缺事实且已开口未回 |
| 未执行 | 本轮未排入或阻塞未解除 |

卡与环境不一致：把**实际响应原文**写入结果 → 判实现/文档/环境问题；文档错则回 T1 改卡，不现场改 cases 凑绿。

### 3. 记录

写 `T2-01-结果-r{N}.md`；证据放 `T2/evidence-r{N}/`（out 摘录、脱敏响应、截图名、查库摘录）。更新 `00-当前位置`。

## 规则

- **不猜**：缺地址/鉴权/入参 → 未执行或无法证明。  
- **不发明**：禁止为让脚本通过而写入卡上没有的 path/body。  
- 自造桩当真环境 ≠ 验收证据。  
- 失败出缺陷用 T3 契约，不用开发 S3 的 A/B/C/D。

## 产出

见 [产出模板.md](产出模板.md)。

## 出口

- 本轮计划内每条均有结果态与证据指针。  
- 失败项已挂 `BUG-xx` 或已说明回炉改卡。  
- 「你要做的」写清：修环境 / 答必问 / 确认 BUG / 进 r2 / 收口。
