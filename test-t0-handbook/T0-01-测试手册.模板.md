## 2. 鉴权菜谱

逐步可照做（账号变量名写这里，值只在 `env.local`）：

1. 打开 / 调用：`{登录页或 POST /{svc}/.../login}`  
2. 请求体字段：`{user}` / `{password}`（变量：`USERNAME` / `PASSWORD`）  
3. 响应令牌字段：`{如 data.token}` → 写入环境变量 `TOKEN`  
4. 后续请求 Header：`Authorization: Bearer {TOKEN}`（若还有固定头：`{Header名}={值或变量}`）  
5. 令牌失效表现：`{码/文案}` → 重新登录  

可选：多端/多应用时的额外头或签名步骤。
