### I-01 最小样例

成功请求（可打码）：

```json
{
  "page": 1,
  "size": 10
}
```

成功响应摘录：

```json
{
  "code": "{手册成功码}",
  "data": { "records": [] }
}
```

失败样例（AC 含反例时必附）：`{码/文案或 HTTP}`。

**出口门禁**：执行方式为 verify 的 AC，对应卡必须「已取样」。
